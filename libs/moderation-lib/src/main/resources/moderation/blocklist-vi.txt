# Text moderation blocklist — Vietnamese, plus the English that turns up in Vietnamese comments.
#
#   term | CATEGORY | severity
#
# severity 3  refused: a comment gets 422 COMMENT_REJECTED, a caption gets 422 VIDEO_*_REJECTED.
#             Only for terms that are abuse in every context they appear in.
# severity 2  held for a person: a comment waits for the video owner's approval, a video goes to
#             admin review. Everything with an innocent reading belongs here, if anywhere.
#
# CATEGORY is one of PROFANITY, INSULT, HATE, SEXUAL, VIOLENCE, SCAM, SPAM, PERSONAL_INFO.
#
# HOW A TERM MATCHES DEPENDS ON HOW IT IS WRITTEN:
#   - with diacritics (or đ)  -> matched only against text with the same diacritics.
#                                "cặc" never matches "các", "lồn" never "lớn", "buồi" never "buổi".
#   - in plain ASCII          -> matched against the text with every diacritic removed, so it
#                                catches all spellings: "dm" matches "đm", "ĐM", "đ.m", "d m".
#   Never add the ASCII form of a word whose folded spelling is an everyday word (cac, lon, buoi,
#   di, deo, vay, ...): it would hold half of all comments. The same goes for a phrase: "ca cuoc"
#   is "cá cược" and also "cả cuộc (đời)", "app vay" is also "app vậy", "vay online" "váy online".
#
# Matching is by whole syllables, never substrings: "sex" does not match "sexy". Repeated letters
# (nguuuu), leetspeak inside a word (d1t), look-alike letters, invisible marks after a letter and
# words spelled out letter by letter (v c l) are undone before matching. A term of two syllables or
# more also matches written as one word, as a hashtag writes it: "nhà cái" catches "#nhàcái".
#
# Before adding a term, search for it in ordinary text: "óc chó" is an insult and also a walnut,
# "xoạc" is crude and also the splits, "súc vật" is livestock. Mild intensifiers that are everyday
# speech (vãi, vl, vcl, đéo) are left out on purpose.
#
# Bump the version on every change: it is stored with every held comment and every screened video.
