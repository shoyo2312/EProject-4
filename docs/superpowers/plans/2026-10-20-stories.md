# Stories Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make stories usable end to end on the web app — post a photo/short video with PUBLIC/FRIENDS/PRIVATE visibility, screened by the existing moderation pipeline, watched from a tray on the Following page.

**Architecture:** story-service presigns uploads into a private `stories/` prefix, saves the story `PENDING_MODERATION`, and announces it through a per-document outbox. media-worker moderates the object and answers with a verdict event; story-service turns it into `ACTIVE`/`HELD`/`REJECTED`. Reads apply video-service's visibility rules against story-service's own copies of bans, closures and private-account flags, and hand out 1h presigned GET URLs. The web app (`../tiktok-cloned`) adds a tray, a viewer, a composer and a profile ring.

**Tech Stack:** Java 21, Spring Boot 4.1, Spring Data MongoDB, Spring Kafka + `kafka-lib`, `moderation-lib`, MinIO Java SDK, JUnit 5 + Mockito; Next.js 16 / React 19 / TypeScript strict / Tailwind v4 / Vitest.

**Spec:** `docs/superpowers/specs/2026-10-20-stories-design.md` — read it first; this plan argues from it.

## Global Constraints

- Story statuses: `PENDING_MODERATION`, `ACTIVE`, `HELD`, `REJECTED`. Viewer reads whitelist `ACTIVE`.
- Visibility enum values `PUBLIC`, `FRIENDS`, `PRIVATE`, same meaning as `VideoVisibility`.
- `expiresAt`: create = `createdAt + 48h`; on ACTIVE = `now + story.ttl-hours` (24); HELD/REJECTED unchanged.
- Accepted types → extension / byte limit: `image/jpeg`→jpg, `image/png`→png, `image/webp`→webp (10 MB = 10485760); `video/mp4`→mp4, `video/webm`→webm (50 MB = 52428800). Video ≤ 60 s.
- Object key: `stories/{userId}/{snowflake}.{ext}`. `stories/` never joins the anonymous-read policy.
- Presigned GET expiry 1h; presigned POST expiry = `minio.url-expiry` (15m, as video-service).
- Image story display time 5 s; video = its `durationSeconds`.
- Topics: `story.story-events` (key `storyId`, `StoryCreatedEvent`), `media.story-moderation-events` (key `storyId`, `StoryModerationCompletedEvent`). media-worker consumer group `media-worker-story-moderation`; story-service group `story-service`.
- `followedUserIds` cap = 500 (video-service `MAX_FOLLOWED_USERS`), else 400 `TOO_MANY_FOLLOWED_USERS`.
- Caption ≤ 300 chars (existing `@Size`). Rejected caption → 422 code `STORY_CAPTION_REJECTED`.
- Repo rules apply: constructor injection, records for DTOs, no `@Data` on documents, MapStruct mapper, `@MockitoBean` not `@MockBean`, Jackson 3 (`tools.jackson.*`), every consumer idempotent, `spring.data.mongodb.auto-index-creation: true`.
- Web: `AGENTS.md` + `FRONTEND_RULES.md` — all calls through `apiFetch`, pure logic in `src/lib/` with a Vitest test, kebab-case hooks, Tailwind only, no comments unless the why is non-obvious, run `npm run check` + `npm test`.
- Work on a branch `feat/stories` cut from `dev` (backend and `tiktok-cloned` each).

## Review Focus

1. **Moderation never answers (media-worker down for hours)** — story stays visible to its owner as "pending", invisible to others, and is gone after 48h. Test: Task 2 `pendingStoryExpiresAfter48Hours`.
2. **Two concurrent `POST /views` from the same viewer** — 204 both times, `viewCount` +1 exactly. Test: Task 2 `duplicateViewIsNoOp`.
3. **Story create with someone else's key, or a key whose object was never uploaded** — 403 / 400, nothing saved. Tests: Task 3 `foreignKeyIsRejected`, `missingObjectIsRejected`.
4. **Verdict redelivered after the story was already decided or deleted** — no state change, no exception. Test: Task 6 `redeliveredVerdictChangesNothing`, `verdictForUnknownStoryIsNoOp`.
5. **Viewer opens a FRIENDS story of a non-friend by id / a private owner's PUBLIC story without following** — 404. Tests: Task 7 matrix + Task 8 `getByIdHidesFriendsStoryFromStranger`.
